# 🎫 QueuePilot

Smart virtual queue with local ticket management and wait-time estimation.

## ▶️ Run

Open `index.html` in a modern browser.

## 🛠️ Stack

HTML5 · CSS3 · Vanilla JavaScript

## 💾 Data

Where applicable, the prototype uses browser LocalStorage. No backend is required.
