# 🔎 LostLoop

Lost-and-found matching prototype using category, location and keyword scoring.

## ▶️ Run

Open `index.html` in a modern browser.

## 🛠️ Stack

HTML5 · CSS3 · Vanilla JavaScript

## 💾 Data

Where applicable, the prototype uses browser LocalStorage. No backend is required.
