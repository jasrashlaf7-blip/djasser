# 🧠 StudyForge

Adaptive study planner with task ranking and a focus timer.

## ▶️ Run

Open `index.html` in a modern browser.

## 🛠️ Stack

HTML5 · CSS3 · Vanilla JavaScript

## 💾 Data

Where applicable, the prototype uses browser LocalStorage. No backend is required.
