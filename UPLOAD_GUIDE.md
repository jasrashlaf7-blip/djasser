# 🚀 Upload Guide

1. Create a **new Public repository** on GitHub.
2. Upload the **contents of this folder** (not the ZIP itself).
3. Commit the files to the `main` branch.
4. The repository homepage will show `README.md`.
5. Click `profile/`, `web-projects/`, `python-projects/`, `android-projects/`, `achievements/`, or `cv/`.
6. For live web demos, enable **Settings → Pages → GitHub Actions**.
7. After the workflow deploys, the root GitHub Pages URL will open the portfolio website.
8. The web projects can also be opened directly from their folders.

## Recommended repository name

`djasser-portfolio`

## Important

For your personal GitHub **profile repository**, GitHub requires a separate public repository whose name is exactly your GitHub username. That repository should contain the profile README you want displayed on your profile.

This package is your **portfolio repository**. It can be linked from your profile repository.
