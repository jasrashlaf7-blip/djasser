# MouthControl

## التحكم بالحاسوب دون استخدام اليدين

مشروع تجريبي لاستكشاف التفاعل مع الحاسوب عبر حركات الفم والأوامر الصوتية.

## ✨ الميزات

- تفاعل دون اليدين
- استكشاف حركات الفم
- الأوامر الصوتية
- فكرة مرتبطة بإمكانية الوصول

## 🛠️ التقنيات
