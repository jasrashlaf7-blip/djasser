## How to use the profile repository

1. Create a **Public** GitHub repository with exactly the same name as your GitHub username.
2. Upload `profile/README.md` as the repository's `README.md`.
3. Keep `README-AR.md` and `README-FR.md` in the same repository.
4. Add screenshots, project links, and your real GitHub username before publishing.

## How to use project repositories

For each project:
1. Create a new repository with the same project name.
2. Copy the matching `README.md` into the repository.
3. Add screenshots to the `assets` folder.
4. Replace placeholder technology lines with the technologies actually used.
5. Add the project URL and any setup instructions.

## Important

The README files intentionally avoid inventing technical features that have not been confirmed yet. Update each project README with the exact features and technologies actually implemented.
